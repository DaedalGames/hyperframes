# HyperFrames v0.8.182

Released on 2026-10-20.

Website capture now handles pages that reload after a cookie banner, CLI commands start faster, and a repeat `check` starts with the CLI and Chrome already up. Renders inside a macOS sandbox no longer fail, a sharp sound at a film's start no longer grows louder with each audio pass, and `lambda sites create` takes source files over 5 GB.

## Fixes

- **CLI:** Website capture waits for a page that reloads after its cookie banner closes, so assets and scroll screenshots are no longer empty ([0693839b5](https://github.com/heygen-com/hyperframes/commit/0693839b52306cbe35ee508f7b4c4b6f914a4fae), [#4949](https://github.com/heygen-com/hyperframes/pull/4949)).
- **CLI:** `check` prints progress while it makes browser-playable copies of phone videos ([b7fa007bf](https://github.com/heygen-com/hyperframes/commit/b7fa007bf3cfb03a62bbb5460009c7e628e3bb2d), [#5953](https://github.com/heygen-com/hyperframes/pull/5953)).
- **CLI:** `check`, `snapshot` and Studio show accented and non-Latin project text correctly instead of garbled ([6d357ff0d](https://github.com/heygen-com/hyperframes/commit/6d357ff0d8dbb88b8d19fe689c15f0808724e52a), [#5843](https://github.com/heygen-com/hyperframes/pull/5843)).
- **CLI:** `check` no longer calls a film static when it moves only through an SVG mask or clip path, a stroke reveal or a canvas ([0bd626825](https://github.com/heygen-com/hyperframes/commit/0bd626825c74c9b692b755345eaea93f66dd0577), [#5960](https://github.com/heygen-com/hyperframes/pull/5960)).
- **CLI:** `check` audits a color-graded video as the video it shows, so the video's layout opt-outs apply and its footage is not read as cut-off text ([9f793a6db](https://github.com/heygen-com/hyperframes/commit/9f793a6dbd42a8b31a30087c478a6d7338645f6c), [#5963](https://github.com/heygen-com/hyperframes/pull/5963)).
- **CLI:** A scoped `keepsMoving` check ignores a changing page background outside its scope ([ba1fa8b12](https://github.com/heygen-com/hyperframes/commit/ba1fa8b12aefcb9cd94ce2e79b62b0cc0cb79cf5), [#5966](https://github.com/heygen-com/hyperframes/pull/5966)).
- **CLI:** The Chrome the CLI launches exits with it, even when the CLI is killed ([434ad8c41](https://github.com/heygen-com/hyperframes/commit/434ad8c41c6fd86b4341c52cc6e751f40474f13f), [#5943](https://github.com/heygen-com/hyperframes/pull/5943)).
- **Studio Server:** On Windows, two history claims on one project at the same moment no longer crash one of them; the second waits for the lock ([468467003](https://github.com/heygen-com/hyperframes/commit/468467003c62d5877f75b080ef8408fb4c963eaa), [#5923](https://github.com/heygen-com/hyperframes/pull/5923)).
- **Producer:** Renders inside an agent's macOS sandbox no longer fail when reading the system uptime ([26a5ab775](https://github.com/heygen-com/hyperframes/commit/26a5ab775b77fde3c2f08839ba34c93f86e7b9da), [#5842](https://github.com/heygen-com/hyperframes/pull/5842)).
- **Producer:** The disk-space error suggests `--workers 1` only when one worker would stream ([f0ef4cb9d](https://github.com/heygen-com/hyperframes/commit/f0ef4cb9d47986d6cc00fcffc95763e6f19b4c15), [#5934](https://github.com/heygen-com/hyperframes/pull/5934)).
- **Engine:** A sharp sound in a film's first moments no longer grows louder with each audio encode, so audio in renders with sound changes slightly ([87c6e50f5](https://github.com/heygen-com/hyperframes/commit/87c6e50f5ea9f4c3d2b4d46a071907466e0f8e01), [#5956](https://github.com/heygen-com/hyperframes/pull/5956)).
- **Core:** Audio volume automation stays correct when the browser refuses an overlapping curve ([e44f456b7](https://github.com/heygen-com/hyperframes/commit/e44f456b7cbf8da6389797f4fb4a776d1ea8885c), [#5927](https://github.com/heygen-com/hyperframes/pull/5927)).
- **Player:** An embed that sets no height shows its film at the film's shape instead of 0 px tall ([46cb5ca44](https://github.com/heygen-com/hyperframes/commit/46cb5ca446c18dbd02e4a618f488d8237bc4482c), [#5932](https://github.com/heygen-com/hyperframes/pull/5932)).
- **AWS Lambda:** `lambda sites create` and Lambda renders upload source files over 2 GiB and over 5 GB ([c8f322c25](https://github.com/heygen-com/hyperframes/commit/c8f322c25910ed224e29ca5d1a62a521e62544cc), [#5964](https://github.com/heygen-com/hyperframes/pull/5964)).
