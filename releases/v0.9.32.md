# HyperFrames v0.9.32

Released on 2026-11-10.

Long films that are slow to open now render instead of failing before their first frame. The CLI, Studio and the renderer also stop a project folder from choosing what they run or serve.

## Features

- **Producer:** The render stream's complete event names the producer version that rendered it ([7afa05a78](https://github.com/heygen-com/hyperframes/commit/7afa05a782c452ca76af22bdde12d4cddaf64c60), [#7515](https://github.com/heygen-com/hyperframes/pull/7515)).

## Fixes

- **Producer:** Long films that are slow to open no longer fail before their first frame: the wait for the first frame now follows how long the browser took to start, up to 15 minutes ([7ff8ece46](https://github.com/heygen-com/hyperframes/commit/7ff8ece461e87282e17f3da14f0b83d0cbe9d38f), [#7517](https://github.com/heygen-com/hyperframes/pull/7517)).
- **Lint:** Flag a script that calls gsap before GSAP loads, and say so when a render fails on it ([124591a9d](https://github.com/heygen-com/hyperframes/commit/124591a9d5d54fb90ab9ab832ced2b3af1527d11), [#7514](https://github.com/heygen-com/hyperframes/pull/7514)).
- **Producer,engine:** Harden render paths, render slots and local listeners ([60fb9d2c5](https://github.com/heygen-com/hyperframes/commit/60fb9d2c5e0c213787888300dd98b8cb05fc2b31), [#7508](https://github.com/heygen-com/hyperframes/pull/7508)).
- **Studio Server:** Harden preview paths, cache folders and local servers ([b8bb49190](https://github.com/heygen-com/hyperframes/commit/b8bb4919003fd5082a0db481271db4baf7701b30), [#7510](https://github.com/heygen-com/hyperframes/pull/7510)).
